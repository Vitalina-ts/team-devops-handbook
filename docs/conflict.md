# Вирішення конфлікту в .editorconfig

Під час злиття виник конфлікт `add/add` у файлі `.editorconfig`, оскільки двоє учасників незалежно створили цей файл з різними значеннями `indent_size`.

## Помилковий спосіб вирішення
Видалити лише маркери конфлікту (`<<<<<<<`, `=======`, `>>>>>>>`), але залишити обидва блоки параметрів.
**Наслідки:** Файл залишиться синтаксично коректним і не видасть помилки, але текстовий редактор застосує останнє значення у файлі. Це ламає передбачуваність, оскільки різні частини команди будуть думати, що діє інше правило.

## Правильний спосіб вирішення
Видалити маркери Git та залишити лише одне узгоджене значення (наприклад, `indent_size = 4`). Це гарантує, що вся команда працюватиме з однаковими відступами.
