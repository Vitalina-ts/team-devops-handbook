# Code Review Checklist

## Build

- [ ] Проєкт збирається без помилок.
- [ ] Немає нових compiler warnings.

## CLI

- [ ] Програма коректно обробляє правильні аргументи.
- [ ] Програма показує зрозумілу помилку для неправильних аргументів.
- [ ] Код завершення відповідає результату виконання.
- [ ] `--help` або `-h` працює, якщо передбачено.

## Input

- [ ] Некоректні вхідні дані не призводять до аварійного завершення.
- [ ] Перевіряється відсутність обов'язкових аргументів.

## Output

- [ ] Вивід не містить зайвої debug-інформації.
- [ ] Повідомлення про помилки зрозумілі користувачу.

## Files

- [ ] Програма коректно обробляє відсутній файл.
- [ ] Перевіряються помилки відкриття/читання файлу.

## Code

- [ ] Зміна не містить закоментованого тимчасового коду.
- [ ] Назви змінних і функцій зрозумілі.
- [ ] Одна функція не виконує кілька непов'язаних задач.
